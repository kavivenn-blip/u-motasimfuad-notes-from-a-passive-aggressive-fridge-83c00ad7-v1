One funny passive-aggressive note a smart fridge leaves for its owner: it kept the salad crisp for nine days, got repaid with a pizza order, and now the crisper drawer has filed for divorce — the hearing is Tuesday.

## Run it

```sh
python3 main.py
```

The program writes the note to `/output/entry.txt` (UTF-8, 137 characters, no trailing newline). It is deterministic, uses no network, and has no dependencies outside this repository.
